# 绽夜 · 版本说明

产品介绍、主要功能和启动方式见仓库根目录 [README](../README.md)。这里保留每一版加了什么，方便对照页面顶栏的 V1–V9。

## 产品版本演进原则

本项目的 V1 至 V9 是同一产品逐步扩展的迭代记录，不是彼此替代的独立方案。每个后续版本都必须保留前一版本已经具备的功能，并在此基础上增加新能力；除非用户明确提出移除或调整，否则不得因新增版本功能而破坏已有能力。

- **V1：** 点击夜空发射基础烟花。
- **V2：** 保留 V1，增加烟花形态选择和文字烟花。
- **V3：** 保留 V2，增加多人连接与烟花同步；玩家进入共同夜空，不提供创建或加入私人房间的功能。
- **V4：** 保留 V3，增加双人近距离点击合并及合并特效；仍不提供创建或加入私人房间的功能。
- **V5：** 保留 V4，增加带房间号和房主自设密码的房间；烟花同步与合并只发生在同一房间。
- **V6：** 保留 V5，增加公共大厅与实时弹幕；用户可进入公共大厅或继续创建、加入密码房间。
- **V7：** 保留 V6，增加烟花作品编辑器；可编辑形状、文字、颜色、大小和速度，将个人作品保存在本地，并分享到私人房间。我的作品和房间分享都用「使用此作品」：启用后点击夜空即按该作品燃放，再点一次取消。
- **V8：** 保留 V7，将烟花文字上限提高到 10 字，加入自定义粒子轨迹播放和房间主题同步；主题只有房主可设置。自然语言生成烟花、文字和房间主题，由服务端读取 `.env` 调用模型接口，密钥不进入浏览器。
- **V9：** 保留 V8，新增「那一夜的银河」面板：选择日期（公元 1–3000 年，含岁差与历法切换）、时刻和城市，以纯本地天文计算还原当晚银河并烟花化呈现；含星光旅程大字幕（织女/牛郎/银心按距离逐条递进讲述光走了多少年）、银河常驻与自然流动（绽放结果不消散，原地转入斗转星移）、银河质感常驻（大暗隙 · 颗粒奶雾双层 · 银心暖色泛光 · 大气消光）、流星雨辐射点（流星从真实辐射点四散）与影院模式时刻时间轴（拨动当下，不是重放），另有斗转星移（星河流转：时间加速快转，众星拖出彗尾）、全天星场（1500 颗确定性生成背景星）、五大行星（JPL 轨道要素真实计算）、月亮与月光（Meeus 月理 + 真实月光冲淡银河）与流星升级（极大期高斯加权、速度定色、火流星余迹）。

后续新增版本时，应沿用这条累积链，并在对应版本的验收中检查此前版本功能仍然可用。

## 版本教学解读

右下角「教学」按钮（或 T 键）打开面向开发者的教学面板：每个版本一张可展开的卡片，包含本版本的 Prompt（开发指令）、主要功能、升级要点、思路迁移和常见问题五个板块；当前版本高亮，卡片内可一键跳到对应版本体验。演进主线：单人玩具 → 联网世界 → 社区规则 → 创作工具 → AI 能力 → 科学致敬。

右下角「收起界面」（H 键，Esc 展开）把顶栏、烟花形状、多人与弹幕输入、底部提示和中心标题一起收起，底部留下一条细条：当前形状、一行弹幕、展开界面。正在飞的弹幕和已经点亮的银河留在夜空里。烟花作品编辑器可收成左缘「编辑」，「那一夜的银河」连同房间分享作品收成右缘「银河」。偏好记在本地。「观影」（F）仍是更彻底的沉浸；「清屏」（R）只清烟花和弹幕，不隐藏界面。

## 启动

需要先安装 [Node.js](https://nodejs.org/)。在项目目录打开终端，然后运行：

```powershell
npm install
npm start
```

服务器启动后，在浏览器打开 <http://localhost:3000>。保持终端窗口运行；按 `Ctrl+C` 可停止服务器。

## 多人连接

页面打开后填写昵称并点击“连接夜空”。同一局域网的其他设备可在浏览器访问运行服务器的电脑地址，例如 `http://192.168.1.20:3000`，然后填写昵称连接。

如果要让不同网络的朋友加入，需要将服务部署到可公开访问的主机，或配置安全的公网隧道，并通过 HTTPS/WSS 地址访问。不要将未经保护的服务器直接暴露到公网。

## 页面文件

- `index.html`：当前主页面，由 Node.js 服务器提供。V1 到 V9 都在这个页面里切换。
- `通信可视化.html`：烟花通信监控页。主页面右下角「通讯」会打开它，以「监控台」昵称连入同一台服务器，查看在线人数、收发计数和事件日志。

## V4 合并烟花

切换到 V4 后，每次点击都会立即正常发射烟花。连接同一夜空的两位不同玩家若在 5 秒内、彼此点击位置相距不超过 60 像素，会在正常烟花之外额外触发大型合并烟花和扩散光环。连接旧服务器时仍可正常发射和同步普通烟花，但需要更新服务器才能触发合并特效。

## V5 房间

切换到 V5 后，房主先自设 4 至 12 位房间密码再创建房间；服务器生成 6 位房间号并自动加入。把房间号和密码发给其他玩家，他们输入两项后即可加入。烟花与在线名单只在同一房间内同步。房间数据保存在服务器内存中，服务器重启后会清空。

## V6 公共大厅

进入 V6 后点击“进入公共大厅”，即可和大厅中的所有用户发送、接收实时弹幕；弹幕会显示用户名并横向飘过。V6 也保留 V5 私人房间和 V4 合并烟花，可通过房间号和房主自设密码进入私人房间；私人房间的消息与烟花仍和公共大厅隔离。弹幕每位用户每 5 秒最多发送 5 条，每条最多 80 字。

## V7 烟花作品

V7 保留公共大厅弹幕、密码房间、合并烟花、形态和文字烟花。编辑作品时可设置形状、文字、主色、大小和速度；作品保存在当前浏览器，最多保留 30 个。加入私人房间后可将作品分享给房友。没有人分享时不显示列表；有作品进来才出现。分享卡片不再单独播放，和「我的作品」一样点「使用此作品」，之后点击夜空都按这份作品燃放；也可以点“保存”收进自己的「我的作品」（记下分享者名字，离开房间后仍然在）。作品分享不开放在公共大厅。

## V8 创作与房间主题

V8 保留 V7 的作品编辑、保存、房间分享、公共大厅和合并烟花。V2–V7 文字烟花继续限制为 6 字，V8 提高到 10 字；自定义轨迹使用受限粒子配方，不运行生成代码。私人房间主题由房主独占设置，并同步给房间成员。自然语言生成烟花、文字和主题通过 Node.js 服务端调用你在 `.env` 中配置的模型服务。

### 配置自然语言生成

编辑项目根目录的 `.env`，填写你自己的模型 API key。项目也提供 `.env.example` 作为配置参考。默认使用 OpenAI 官方 API；也可以切换到 DeepSeek。

```env
AI_API_KEY=你的模型服务密钥
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
```

使用 DeepSeek 时，设置 `AI_PROVIDER=deepseek`，然后填写 `DEEPSEEK_API_KEY`。默认地址和模型如下；如需选择 DeepSeek V4 Pro，可将模型改为 `deepseek-v4-pro`。

```env
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的DeepSeek密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

`.env` 只由 Node.js 服务端读取，网页不会接触 API key。生成烟花、文字和主题时，描述会经本项目服务端发送给 `.env` 中指定的模型服务。每个来源地址每分钟最多请求 8 次。房间主题只有私人房间房主可以应用。修改 `.env` 后需要重启服务器。

## V9 那一夜的银河

切换到 V9 后，右侧面板选择日期、时刻和观察城市，点击「绽放那一夜的银河」即可重现当晚银河的真实走向。计算完全在浏览器本地完成：银道坐标经岁差修正（IAU 1976，J2000 → 当年分点）与 ΔT 修正后经恒星时换算为地平坐标，地平线以上的银河带以成形粒子勾勒，银心方位与高度、织女星、牛郎星、天津四的位置，月相亮度与当夜主要流星雨（英仙座、双子座等 8 个，含辐射点方位与高度）都会如实呈现并写入面板摘要；全天另有 1500 颗确定性生成的背景星场、按 JPL 轨道要素计算的五大行星与按 Meeus 月理计算的月亮（满月高悬时整幅天穹泛起月光纱罩，银河被如实冲淡）。银心在地平线下的日期（如冬季）会如实提示。该功能不联网、不消耗 AI 配额。

V9 附加能力（均在「那一夜的银河」面板内）：

- **星光旅程大字幕：** 绽放进入影院模式后，「光走了多少年」不再混在信息小字里，而是以大号居中字幕按距离**逐条递进浮现**（每条间隔 3.8 秒、展示约 2.9 秒，全程约 11 秒）：织女星 · 25 光年（「这缕光出发时，人间正过着 2001 年」）→ 牛郎星 · 17 光年（「它比织女星的光晚出发 8 年——此刻隔河相望的两颗星，并不在同一个『现在』」）→ 银心 · 约 2.6 万光年（仅当夜银心可见时：「它走了两万六千年，走到你的今夜」）。早于公元 1 年自动换算为公元前。银河波次成形一铺满（约 4.5 秒）就无缝转入随时间流动的常驻星空，**不等字幕讲完**——大字幕在流动的星空上继续讲（见「自然流动的银河」）。常规信息（日期、银心方位、流星雨、月相）仍走底部小字幕。
- **星名常驻标注：** 织女星、牛郎星、天津四在地平线上时，星点旁会出现**带引线的常驻名字标注**，每颗星还围着一圈 8 点呼吸光环，在整条银河里一眼可辨——「字幕里说的星」从此有名字、有位置。七夕之夜织女星标注呈粉色、牛郎星呈青色，双星会心的两道流光正是从这两颗被标出的星升起。时刻预览同样显示标注（随预览替换）；守夜模式下标注与光环**跟随星星实时移动**，星沉入地平线时一并退场。清屏、重新绽放或切走版本时自动清理。
- **方位参照（东 · 南 · 西 · 北）：** 默认隐藏，需要时在面板勾选打开——地平线上出现**常驻的小号方位标**（11px 淡蓝字，贴在岸线剪影上方，不挡银河）：南在画面中央，东、西按方位角摊开在两侧；北在观星者身后，按星空软件惯例在画面左右两端各贴一枚更淡的小标（越过去就是北）。整个绽放与流动观赏过程全程在场，观赏中开关即时增减；预览拖时刻时同样显示。偏好记忆在本地。
- **银河质感（常驻，全面加强）：** 默认即是质感效果（开关已移除），四层增强常驻——① 采样密度提高约 5 倍（银经 2° 步进 × 纬度 9 档），大暗隙（银经 25°–95°，带心最暗、向两翼减弱）真正显形为「银河中间裂开的黑河」；② 颗粒奶雾双层渲染：每颗锐利星点簇生 3 枚更小更暗的邻点，全场无大颗粒，远看是颗粒奶雾、近看颗颗是星（真实银河的雾感即来自大量暗弱恒星的累积）；③ 银心附近混入暖白微金色星点；④ 大气消光——低空星点偏橙红、高度越低越暗。
- **活着的银河：** 绽放后银河不是静态画——① 成形自银心向外**波次蔓延**（约 4.5 秒铺满全场，银心先亮、两翼后到）；② 停留期整条银河以**行波方式流动**——亮度波沿银经方向缓缓推进（约 5 秒一个周期，每粒相位随银经递增），看久了像整条河在朝一个方向淌；③ 流星按守夜的节奏偶发划过（先静一会儿，再来一道；极大夜更密，仍留空档），夏季大三角星点同步强呼吸。守夜流动中星空位移按**大气折射压扁映射**：屏幕纵向随高度角压缩（近地平线 dy/dalt → 0），星星升起沉落只剩岸线处柔和的出现与消失——没有可感知的「升降位移」，更没有垂直坠落感，银河只是安静地流。
- **流星雨辐射点（流星有母题）：** 八大流星雨各配真实辐射点坐标（象限仪、天琴、宝瓶η、英仙、猎户、狮子、双子、小熊）。活跃之夜且辐射点已升出地平线（高度 > 6°）时，流星从辐射点向外散开：多数挑会切开银河、大暗隙，或从织女与牛郎之间掠过的方向；大约三成是靠近辐射点的短痕，大约一成半贴着岸线拉一条长痕。辐射点本身不标亮。辐射点未升起时，流星仍尽量横过银河，不再从画面顶部斜着掉下来。每颗流星是一道线：头部白热，尾巴细长渐隐，靠近辐射点的短，横穿画面的长。颜色按进入大气的速度：双子、小熊偏暖金，英仙偏冷白，宝瓶η、猎户、狮子偏青白。
- **斗转星移（星河流转的活天空）：** 流动期间点时间轴上的「斗转星移」，时间加速到 1 真实秒 = 45 模拟分钟（约 8 秒走过 6 小时星空、32 秒绕天极一圈）。星点仍画在每帧清空的星空层（底色保持干净）；因加速而拉出的短彗尾叠进单独的流光层，只留亮色、较快淡出，不盖黑底——快转时众星连成细线流光，又不会在流动前几十秒蹭出暗色脏弧。所有带钥匙的星空粒子（银河带、颗粒奶雾、亮星）各自按平滑速度拖出短彗尾：织女星拖着尾光升起又落下，银心整条过顶；星空铺满整页，快转的流光直接漫过整幅画面（岸线剪影不反光，快转时也没有任何垂直雨）；星星升出或沉入地平线都**原地渐显 / 原地谢幕**（压扁映射让近岸位移放缓，沉没时惯性清零、位置冻结，绝不坠入大地剪影）——快转的星空里找不到一滴「星雨」。星名标签全程跟随，看得到每颗星的名字掠过天际。流星照常飞行（辐射点母题不变），烟花、双星会心、银心点燃也都照常——快转的星空之上放烟花反而更热闹。**星空是真循环**：连转超过一圈（32 秒 = 24 小时模拟时）后，西沉的星会随「下一夜」从东方再次升起，第二圈与第一圈同样满天星流；模拟钟跨过午夜时日期真实推进（流星雨日历跟着换夜），越过分点接缝（方位角 ±180°，画幅两缘）的星从一侧边缘消失、从另一侧入场，不会横穿画幅拖出假彗尾。摘要给出银心高度提示：银心还在低空时会建议拨时间轴到凌晨、或换个夏季日期看银河过顶。拨动时间轴的瞬间彗尾自动收拢重估，不会画出横穿画幅的直线。再点一次退出：速率回到原档、彗尾消失，星空回到舒缓流动；重新绽放 / 清屏 / 切走版本时自动收起。
- **全天星场（不止银河一带）：** 在银河带之外，内置一份**确定性生成的全天亮星目录**（1500 颗，IIFE 种子随机数逐颗生成，同一天刷新不变）：银纬按真实球面分布、朝银道面幂律聚集，星等取幂律分布、光谱型按 O/B→M 六档着色（蓝白→橙红），避开织女、牛郎等命名亮星。全天星场走守夜池管线：同样从东边升起、向西沉没、随时间流动，斗转星移时同样拖出彗尾——冬季猎户、夏季天蝎不再缺席，整幅天穹都是星。
- **五大行星（夜空里的漫游者）：** 金木水火土按 **JPL 近似轨道要素**（J2000 历元 + 每世纪变率）真实计算：解开普勒方程得日心位置 → 地心视坐标 → 黄赤变换 → 岁差修正 → 恒星时换算出高度方位，行星按视亮度定大小，升起后**柔光晕 + 行星名标注**全程在场。行星会随夜晚沿黄道缓慢挪动、与其他行星相合——拨动时间轴能看到它们与群星不同步的「漫游」。火星偏橙红、土星偏暖黄，各有其色。
- **月亮与月光：** 月亮按 **Meeus 截断月理**真实计算（黄经 13 项 + 黄纬 5 项），盘面用 clip 遮挡法渲染真实月相：亮肢方向随盈亏（北半球盈月亮西）、凸月补亮、弦月压暗、暗面保留地球照微光，低空时按「月径幻觉」略微放大，升起渐显、带柔光晕。**月光是真实的光污染**：照度 = 照亮比例 × 地平高度，满月高悬时整幅天穹泛起蓝灰纱罩，银河与暗星被冲淡——望申之月看不成银河，正是古人「月明星稀」的天文学底色；新月前后银河最浓。
- **流星升级（节奏、速度与火流星）：** ① 节奏是守夜，不是节拍器。没有流星雨大约 14–28 秒一道，活跃期大约 9–17 秒，极大夜大约 4.5–9 秒，间隔在区间里随机；大约两成会紧接着再来一道。后半夜到黎明间隔缩短。斗转星移快转时略密，仍不会下成雨。② 颜色见上一条，速度即颜色。③ 每一夜只给一颗火流星：笔画更长、更亮，头大约一秒走完，并留下被高空风吹歪的烟痕。烟痕还在时，诗句出现在那一道旁边：「这条河的光走了两万年 / 这一道只活一秒」，不走底部字幕。同一场绽放只说一次；守夜跨过午夜后，新的一夜可以再有一颗火流星，这句话不再重复。横穿银河的流星尾巴更长，靠近辐射点的仍然短。
- **全屏银河 + 岸线剪影（整个页面都是星空）：** 地平线从屏幕 3/4 高度下移到约 93%——星空铺满整页，银河拱桥从左下横贯天顶再落向右侧，低空的河段也一直延伸到岸线才收住。岸线以下不再有任何水面渲染：只有一道**确定性起伏的远山剪影**（三种频率正弦叠加，每帧完全一致，不闪烁、不反光）与近乎纯黑的暗色大地，给构图一个「人在岸上仰望」的支点。曾经的整套水面层——映像光河、月路、银心光带、亮星银线、碎金、风痕、烟花水斑、流星光痕——连同沉没星坠水的可能性一并退役：**星星的谢幕是原地渐隐，垂直雨在结构上不可能发生**。月路银带虽已不在，月光仍是真实的光污染：满月夜天穹照旧泛白、银河照旧被冲淡。烟花粒子坠过岸线时在大地里柔和变暗几帧再消失，不做硬切。
- **七夕双星会心（农历自动识别）：** 面板内置完整天文农历换算（1900–2100 年，闰月规则按「冬至定月 + 无中气置闰」处理）。当晚逢七月初七时：① 织女星与牛郎星各升起一道流光（粉 × 青），沿弧线跨过银河**汇聚成心**——复用 V4 合并特效的贝塞尔汇聚轨迹、碰撞光环与大烟花，终点合成一朵 1.8 倍的大爱心烟花，并弹出「七夕 · 双星会心」横幅；② 两颗星标注放大并加强脉冲；③ 大字幕开头多一条「七夕 · 双星会心」，底部小字幕缀上「今夜七夕，双星会心」，时刻预览也会标出会心汇聚点。其他日子不出现。
- **自然流动的银河（默认，常驻不散，真正无缝）：** V9 首页的银河不再是「绽放十几秒后像烟花一样散场」——绽放粒子全部改为常驻（不再自动消散），银河波次成形一铺满全场（约 4.5 秒，不等待字幕），守夜引擎**按采样钥匙原地认领同一批粒子**接管星空：不消散、不再成形、没有任何「重新绽放」的痕迹，只是开始随时间流动。模拟时刻以 1 真实秒 = 3 模拟分钟的舒缓速率推进，银河带缓缓西移旋转（约每秒 3 像素，可感知而不急），东边的星从地平线升起渐显、西边的沉入地平线消散，织女星、牛郎星、天津四与银心全程跟随，流星偶发划过，时间轴钟面逐分钟流转——像真的置身山间看着银河走过整夜。绽放时就把即将流动的整片星空种好（同一套河带锚点、全天星场、银心、命名亮星、行星与月亮），接管只是开始随天转动：没有凭空跳出的星，也没有留在原地再消失的星。清屏（R 键）或切走版本才熄灭。**星空永远纯黑：** 星体、月亮、行星、流星和岸线画在每帧清空的星空层上，流动不会写进会残留的拖尾层。8-bit 画布上半透明盖色有取整死区，星星走过的像素会停在另一种黑上，和底色永远对不齐，刚开始流动的几十秒里整片轨迹就像脏了一层；星空层每帧清空后，走过的地方和没走过完全一样。烟花仍在下层褪色拖尾，夜空里没有烟花时这一层直接清空。
- **守夜加速（独立开关）：** 想看「星移斗转一整夜」时勾选「守夜加速」，流动速率即刻切到 1 真实秒 = 10 模拟分钟（约 48 秒走过 8 小时）；取消勾选回到 1 秒 = 3 分钟的舒缓观赏。切换只变速率，星空不消散不重建。偏好记忆在本地。
- **影院模式时刻时间轴（拨动当下，不是重放）：** 绽放进入影院模式后，屏幕底部浮现半透明迷你时间轴（滑杆 + 时间数字 + 「重放这一夜」按钮）。**绽放前**拖动：全屏原地成形地显示那一段时刻的银河预览（粒子就地出现、不飞散成形，节流 180ms，不计数不响音效）——牛郎织女星标记、七夕会心汇聚点、银心位置点、当夜流星预演都会随时刻同步出现，摘要同步给出银心提示（已跃出地平线 / 正贴近地平线 / 还在地平线下几度）与七夕标签，拖到满意的时刻点「重放这一夜」正式绽放。**银河进入自然流动后**，拖动时间轴不再是「重采样重放」，而是把夜空**拨到所拖的那一刻**——粒子原地换位继续流动，不消散、不再放烟花，按住期间停在那一刻，松手 2 秒后从该时刻继续流动；流动中点「重放这一夜」也只会拨到面板时刻继续流动。滑杆与面板时刻输入框双向同步；清屏（R 键 / 按钮）会一并收起时间轴与旅程字幕。
